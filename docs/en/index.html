Make yourself at home.

Clone the repository, then build and install locally. No extra dependency packages to install.

You’ll need macOS 14 or later, Xcode with Command Line Tools, and Git. Installation asks for your administrator password once.

To keep distribution costs down, Clamsomnia is currently available as source on GitHub rather than through the App Store.

Terminal
git clone https://github.com/mytory/clamsomnia.git
cd clamsomnia
./Scripts/install.sh
open /Applications/Clamsomnia.app

Open Xcode once to finish its initial setup. Check that the build tools are available with xcodebuild -version.

One little cat.
That’s all.

Lives in the menu bar, out of your Dock. Turn it on when you need it. Turn it off when you’re done.

  1. Choose a duration on first launch.

    The initial value is 300 minutes. Choose unlimited if you prefer, and change it in settings whenever you like.

  2. Left-click the cat to toggle.

    Right-click to see the time remaining, the restore deadline, or open settings.

  3. Make it fit your workflow.

    Choose a battery threshold, automatic lock prevention, launch at login, and activation on launch independently.

A few things to know

Does it only prevent sleep when the lid is closed?

It disables system sleep, so it also affects other sleep situations. macOS may still sleep under low battery or thermal conditions. Check heat and battery levels when carrying your Mac in a bag.

Does automatic lock prevention change my password settings?

No. It suppresses idle display sleep and the idle screen saver during an app-owned prevention session. It does not unlock an already locked screen or override manual locking, lid closure, or administrator security policies. Keeping the display on can use more battery.

What happens when I quit, or want to sleep now?

Quitting restores the sleep setting for sessions started by the app. It does not automatically remove sleep prevention started by another tool. To sleep immediately, right-click the cat and choose the command to disable prevention and sleep.

How do I update or uninstall?

To update, quit the app, run git pull --ff-only in the repository, and reinstall with ./Scripts/install.sh. To uninstall, quit the app and run ./Scripts/uninstall.sh. This removes both the app and its privileged helper.
