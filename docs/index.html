필요한 시간만큼

분 단위로 방지 시간을 정하거나 무제한으로 두세요. 시간이 끝나거나 앱을 종료하면 앱이 켠 잠자기 방지는 해제됩니다.

배터리를 남겨 두세요

잔량이 설정한 % 이하가 되면 자동으로 잠자기를 허용합니다. 배터리로 사용 중일 때만 적용하며, 강제로 재우지는 않습니다.

☼

화면도 깨어 있게

원하면 화면 자동 꺼짐과 유휴 화면 보호기도 억제하세요. 수동 잠금과 조직의 보안 정책은 그대로 적용됩니다.

터미널을 열고,
설치하세요.

저장소를 받아 로컬에서 빌드하고 설치합니다. 의존성 패키지를 따로 설치할 필요는 없습니다.

macOS 14 이상, Xcode와 Command Line Tools, Git이 필요합니다. 설치 중 관리자 암호를 한 번 요청합니다.

앱스토어 등록 비용을 아끼기 위해, 현재는 GitHub에서 소스로 배포합니다.

Terminal
git clone https://github.com/mytory/clamsomnia.git
cd clamsomnia
./Scripts/install.sh
open /Applications/Clamsomnia.app

Xcode를 설치한 뒤 처음 실행해 초기 설정을 마치세요. 빌드 도구는 xcodebuild -version으로 확인할 수 있습니다.

자세한 설치 안내문제 신고

작은 고양이 하나면
충분합니다.

Dock을 차지하지 않고 메뉴 막대에 머뭅니다. 필요할 때 켜고, 끝나면 끄세요.

  1. 처음에는 방지 시간을 정하세요.

    기본 입력값은 300분입니다. 무제한도 선택할 수 있고, 설정에서 언제든 바꿀 수 있습니다.

  2. 고양이를 좌클릭하면 켜지고 꺼집니다.

    우클릭하면 남은 시간과 복구 시한을 확인하고 설정을 열 수 있습니다.

  3. 설정에서 내 작업에 맞추세요.

    배터리 임계값, 자동 잠금 방지, 로그인 시 실행과 앱 실행 직후 활성화를 각각 선택하세요.

알아 두면 좋은 것

덮개를 닫았을 때만 잠자기를 막나요?

시스템 잠자기 자체를 비활성화하므로 다른 잠자기 상황에도 영향을 줍니다. 배터리 부족이나 과열 등에서는 macOS가 잠들 수 있습니다. 가방에 넣어 이동할 때는 발열과 배터리를 확인하세요.

자동 잠금 방지는 암호 설정을 바꾸나요?

아니요. 방지 세션 동안 화면 꺼짐과 유휴 화면 보호기를 억제합니다. 이미 잠긴 화면을 풀거나 수동 잠금, 덮개 닫기, 관리자의 보안 정책을 무효화하지 않습니다. 화면 유지로 배터리 소모가 늘 수 있습니다.

앱을 종료하거나 Mac을 직접 재우려면?

앱을 종료하면 앱이 직접 켠 방지 세션을 복구합니다. 다른 도구가 켠 방지는 종료만으로 해제하지 않습니다. 직접 재우려면 우클릭 메뉴에서 ‘방지 해제 후 잠자기’를 선택하세요.

업데이트와 제거는 어떻게 하나요?

업데이트는 앱을 종료한 뒤 저장소에서 git pull --ff-only을 실행하고 ./Scripts/install.sh로 다시 설치하세요. 제거는 앱을 종료하고 ./Scripts/uninstall.sh를 실행하세요. 앱과 관리자 도우미가 함께 제거됩니다.
